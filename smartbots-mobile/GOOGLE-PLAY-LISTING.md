## Descrição curta
CRM simples com bot, agenda, mensagens e WhatsApp assistido para pequenos negócios.

## Descrição longa
SmartBots Hoje é um app para pequenos negócios organizarem contatos, oportunidades, agenda, mensagens e ações comerciais em um só lugar.

Com o app, o usuário pode acompanhar o que precisa fazer no dia, ver leads e prospects, abrir mensagens prontas no WhatsApp, configurar link de agenda, acessar o mini site do negócio e usar recursos de prospecção assistida.

Principais recursos:

- CRM simples para pequenos negócios
- Ações do dia para responder clientes e oportunidades
- Mensagens prontas com abertura no WhatsApp
- Mini site com bot para usar na bio, QR Code e divulgação
- Agenda Pro com link de agendamento externo
- Prospecção assistida para encontrar potenciais clientes
- Painel de contatos, oportunidades e prospects
- Integração com o painel web SmartBots para configurações avançadas

O app não faz disparo automático de mensagens nesta versão. As mensagens são sugeridas e o envio final acontece pelo WhatsApp do próprio usuário.

SmartBots Hoje foi criado para negócios que querem vender mais com simplicidade, sem precisar operar um CRM complexo.

## Data Safety - orientação inicial
O app pode coletar dados de identificação e contato do responsável pelo negócio, dados do negócio, conteúdo cadastrado pelo usuário, leads, prospects, conversas com o bot e configurações de agenda. Esses dados são usados para fornecer CRM, bot, agenda, mensagens assistidas, prospecção e suporte. Não vender dados pessoais.
